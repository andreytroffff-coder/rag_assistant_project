# RAG (Retrieval-Augmented Generation) – структура и реализация

RAG – это подход, который комбинирует **поиск релевантных документов** (retrieval) и **генерацию ответа** (generation) с помощью LLM. Система сначала находит в базе знаний фрагменты, близкие к вопросу, затем передаёт их в модель как контекст.

## Компоненты RAG-системы

1. **Индексация (офлайн)**  
   - Загрузка документов (txt, pdf, md, html, ...)  
   - Чанкинг – разбиение на фрагменты (обычно 500–1000 символов, с перекрытием)  
   - Создание эмбеддингов через `sentence-transformers` или OpenAI API  
   - Сохранение векторов + текста + метаданных в векторную БД (Qdrant, Chroma)

2. **Поиск (онлайн)**  
   - Приём вопроса пользователя  
   - Вычисление эмбеддинга вопроса  
   - Поиск `top_k` ближайших векторов в БД  
   - Возврат соответствующих текстовых чанков

3. **Генерация**  
   - Формирование промпта: `"Контекст: ...\nВопрос: ...\nОтвет:"`  
   - Передача в LLM (локальную через `llama-cpp-python` / `ollama`, или облачную через OpenAI)  
   - Получение и возврат ответа
