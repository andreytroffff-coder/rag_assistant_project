# FastAPI: теория работы и основы

FastAPI — это современный, высокопроизводительный веб-фреймворк для Python, предназначенный для создания REST API. Он основан на стандартных подсказках типов Python (type hints) и асинхронности (asyncio).

## Почему FastAPI?

- **Высокая производительность** — один из самых быстрых Python-фреймворков (наравне с Node.js и Go), благодаря использованию Starlette для сетевых операций и Pydantic для валидации данных.
- **Автоматическая документация** — интерактивные документации Swagger UI (`/docs`) и ReDoc (`/redoc`) генерируются автоматически на основе вашего кода.
- **Валидация данных** — на основе Pydantic: вы описываете модели (схемы), и FastAPI автоматически проверяет типы, преобразует данные и возвращает понятные ошибки.
- **Асинхронность из коробки** — поддерживает `async`/`await`, что позволяет эффективно обрабатывать I/O-операции (базы данных, сетевые запросы, чтение файлов).
- **Автоматическая сериализация** — возвращаемые Python-объекты (словари, списки, Pydantic-модели) автоматически преобразуются в JSON.
- **Поддержка WebSocket, GraphQL (через дополнительную библиотеку), фоновые задачи, CORS, middleware и т.д.**

## Базовая архитектура

FastAPI построен поверх двух ключевых библиотек:

1. **Starlette** — ASGI-фреймворк для работы с сетью, маршрутизации, middleware, WebSocket, статических файлов.
2. **Pydantic** — для валидации, сериализации и десериализации данных на основе аннотаций типов.

## Минимальное приложение

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "Hello World"}

@app.get("/users/{user_id}")
def get_user(user_id: int, q: str = None):
    return {"user_id": user_id, "query": q}
